# PeopleSafe Checkout (MySOS Device Sign-Out)

Tkinter desktop app used to log which PeopleSafe device is signed out to which engineer, and when it is signed back in.

- Maintained by: Lewis Li, from 29-Oct-2026
- Original author: Mislav Prohaska (inherited code)
- Current version: v4 (`src/PeopleSafe_Checkout_app_v4.py`)

## Requirements

- Windows (uses `winsound`)
- Python 3.x with Tkinter (included in the standard Windows installer)
- Pillow (`PIL`), used to load the button images
- PyInstaller, only needed to build the exe

Install:

```
py -m pip install pillow pyinstaller
```

Check what is installed: `py -m pip list`

## How to use the app

1. Choose the RM-Team (A to E).
2. Type the engineer name.
3. Choose the shift.
4. Choose the device.
5. Choose the condition (Good or Broken).
6. Press **Sign-Out**.

To sign a device back in, click its row in the table, then press **Sign-In**.

## Build the exe

Run from the project root (the folder containing `src`):

```
py -m PyInstaller --onefile --noconsole --name PeopleSafe_Checkout_app --add-data "src/*.png;." src\PeopleSafe_Checkout_app.py
```

The exe appears in `dist\`. Copy it to the Live folder next to the real `equipment_log.csv`. Do not run the app from `dist\` or `build\`.

Install Pillow before building, or the exe will crash with "No module named PIL". If the exe closes or misbehaves, rebuild without `--noconsole` to see the error message.

## Data

- Real log: `equipment_log.csv` next to the exe. It contains engineer names, so it must **never** be committed to Git.
- Columns: Engineer Name, RM-Team, Device-Allocation, Sign-Out Date, Sign-In Date, Shift, Condition
- Date format: `29-Oct-2026 14:30`
- Back up the real CSV with a dated copy before every rollout.

- Do not keep the CSV open in Excel while the app is running. Excel locks the file.

## Rollout checklist

1. Back up the live `equipment_log.csv` (dated copy).
2. Test the new build with a test CSV.
3. Copy the new exe to the Live folder.
4. Keep the previous exe in a `Previous` folder for a few days.
5. Tell the team what changed.
